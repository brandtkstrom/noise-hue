# Noise Hue v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the finished docked prototype to a Vite + TypeScript vanilla web app, adding a sleep timer and saved presets.

**Architecture:** Pure, unit-tested modules (catalog, settings/validation/persistence, mappings, DSP generators, timer, presets, viz math) under a thin DOM layer. One typed store holds settings; a second holds transient app state. The audio engine, UI modules and visualizer subscribe to stores and never call each other directly; `main.ts` wires them.

**Tech Stack:** Vite 8, TypeScript ~6.0 (strict), Vitest 5 + jsdom, ESLint 10 + typescript-eslint 8, Prettier 3. No runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-10-13-noisehue-design.md` — read it alongside this plan. Visual/behavioral reference: `docs/prototype/prototype-docked.dc.html` (port exact formulas, copy and colors from it when this plan says "from prototype").

## Global Constraints

- Node `^20.19.0 || >=22.12.0` (Vite 8 floor); `.nvmrc` = `22`.
- `typescript` pinned `~6.0.3` (typescript-eslint 8 supports `<6.1.0`).
- `tsconfig`: `strict: true`, `noUncheckedIndexedAccess: true`, `noUnusedLocals`, `noUnusedParameters`, `verbatimModuleSyntax`.
- No UI framework, no runtime npm dependencies.
- Units: rem for type/spacing/sizes, px only for borders/shadows; `100dvh` (never `100vh`); breakpoints `62.5em` (desktop ↔ mobile), `50em` (3→2 color columns), `31.25em` (2→1).
- Storage keys: `noisehue:settings`, `noisehue:ui`, `noisehue:presets`; legacy `noise-app-config`, `noise-app-panes` imported once, never modified.
- All `localStorage` access wrapped in try/catch; failure = don't persist.
- Fixed config values exactly as spec §2 (start `white`, volume 50, dB floor −40, glow, squared, srgb, eased, opacity 20 %, waves motion speed 1 / intensity 0.5 / sync off, ring `ripple`, dot `bounce`, waveform hidden when stopped, no backing).
- Status colors: paused `#F2867E`, muted `#EBC66A`, playing `#74D69A`.
- Copy (descriptions, labels, value text) verbatim from the prototype.
- Respect `prefers-reduced-motion` for every animation.
- Environment: commands run in the project root `~/Projects/noisehue` (from the Linux VM shell: `$HOME/mnt/Projects/noisehue`). `node_modules` installed there is Linux-only; the final step tells the user to `rm -rf node_modules && npm install` on macOS. Commits end with the Co-Authored-By / Claude-Session trailer lines.

## Review Focus

1. **Corrupt or out-of-range saved data** (hand-edited storage, old prototype keys with junk) → app loads with per-field defaults, never throws. *Pinned in Task 3:* `persist.test.ts › sanitizes junk fields individually`.
2. **Rapid color switching / preset applying while playing** → never more than one fading-out and one active voice; stale voices are stopped. *Pinned in Task 6:* `engine.test.ts › rapid switchTo keeps at most two live sources`.
3. **Pause/play around the sleep timer** (pause mid-fade, play again) → timer cancelled, level restored to full on next play. *Pinned in Task 7:* `timer.test.ts › pause during fade cancels and resets` and Task 6 `fadeOut is cancelled by play`.
4. **Storage unavailable** (Safari private mode, quota) → settings changes still apply in-session; no exceptions. *Pinned in Task 3:* `persist.test.ts › throwing storage is tolerated`.
5. **Keyboard-only use** of fullscreen exit, timer popover and unpinned panels → Esc/any-key exits fullscreen; Esc closes popover and returns focus; Tab into a rail opens its panel. *Pinned in Task 12:* `transport.dom.test.ts › popover Esc returns focus` and `fullscreen exits on key`; Task 10: `panels.dom.test.ts › focus inside rail opens panel`.
